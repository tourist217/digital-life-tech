# Инструкция по деплою DigitalLife Tech (digital-life.tech)

Ваш сайт полностью готов, протестирован и оптимизирован под Next.js 16 + React 19 + Tailwind CSS.

---

## Шаг 1. Отправка репозитория на GitHub

1. Зайдите на [github.com](https://github.com) и нажмите **«New repository»** (Создать новый репозиторий).
2. Назовите его, например, `digital-life-tech` (сделайте публичным или приватным — на ваш выбор).
3. В терминале в этой папке выполните две команды (замените `ВАШ_ЛОГИН` на ваш ник в GitHub):
   ```bash
   git remote add origin https://github.com/ВАШ_ЛОГИН/digital-life-tech.git
   git branch -M main
   git push -u origin main
   ```

---

## Шаг 2. Деплой на Vercel (бесплатно)

1. Зайдите на [vercel.com](https://vercel.com) и войдите через ваш аккаунт GitHub.
2. Нажмите синюю кнопку **«Add New...» → «Project»**.
3. Выберите из списка ваш репозиторий `digital-life-tech` и нажмите **«Import»**.
4. Все параметры Next.js Vercel определит автоматически. Нажмите кнопку **«Deploy»**.
5. Через 40–60 секунд сайт будет запущен в глобальной сети на адресе вроде `digital-life-tech.vercel.app`.

---

## Шаг 3. Привязка домена digital-life.tech из Reg.ru

1. В панели проекта на Vercel перейдите в **Settings → Domains**.
2. Введите ваш домен: `digital-life.tech` и нажмите **«Add»**.
3. Vercel покажет две стандартные записи для DNS:
   - **A-запись**:
     - Имя (Host): `@`
     - Значение (Value): `76.76.21.21`
   - **CNAME-запись** (для www):
     - Имя (Host): `www`
     - Значение (Value): `cname.vercel-dns.com`
4. Зайдите в личный кабинет [reg.ru](https://www.reg.ru), откройте раздел **«Мои домены» → digital-life.tech → «Управление зоной DNS»** (или «Ресурсные записи»).
5. Добавьте указанные записи A и CNAME (или замените существующие).
6. В течение 15–60 минут DNS обновится по всему миру, и Vercel автоматически выпустит бесплатный SSL-сертификат (https).

---

## Шаг 4. Подключение Яндекс Метрики (по желанию)

1. Создайте счетчик в [metrika.yandex.ru](https://metrika.yandex.ru) для домена `digital-life.tech`.
2. Скопируйте номер счетчика (ID, например `12345678`).
3. В файле [src/app/layout.tsx](file:///src/app/layout.tsx) можно вставить готовый скрипт Яндекс Метрики в тег `<head>`.
